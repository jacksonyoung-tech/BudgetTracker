# BudgetTracker

A C# desktop application for calculating and managing personal budgets.

BudgetTracker is my first portfolio C# project, built as part of my transition into IT. The project is being developed incrementally to practise C# programming, Windows Forms development, problem solving, and Git version control.

## Features

### v0.1.0

* Enter weekly income
* Add and remove bills
* Calculate remaining money
* Basic input validation
* Handles bills exceeding available income

### v0.2.0

* Added bill descriptions
* Added `Bill` class
* Added bill due dates
* Improved bill list display
* Refactored the project to use a collection of `Bill` objects

### v0.3.0 — In Development

* Weekly, fortnightly and monthly income options
* Pay date selection
* Calendar-based income calculation
* Monthly income calculated from the number of pay cycles
* Continued improvements to budget calculations
